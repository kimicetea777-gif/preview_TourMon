# 인덱스 페이지 구동 스크린샷

`src/app/page.tsx`(인덱스 페이지)가 이 폴더의 이미지를 참조합니다.
아래 파일명 그대로 넣으면 됩니다. 파일이 없으면 페이지에 alt 텍스트만 노출됩니다.

| 파일명     | 화면                     |
| ---------- | ------------------------ |
| `map.webp` | 배경 지도 + 관광지 마커  |
| `egg.webp` | 알 획득 / 부화 진행도    |
| `dex.webp` | 도감(수집한 몬스터 격자) |

## 권장 사양

- 포맷: WebP (PNG도 동작하지만 `src/content/home/landing.ts`의 `src` 확장자도 같이 바꿀 것)
- 비율: 9:19.5 세로 (일반적인 안드로이드 폰 화면). CSS `aspect-ratio`로 크롭되므로 정확히 안 맞아도 됨
- 크기: 폭 1080px 내외면 충분 (3열로 축소 표시됨)
- 상태표시줄/네비게이션 바는 빼고 앱 화면만 담는 편이 깔끔함

캡처 후 이 README는 지워도 됩니다.
